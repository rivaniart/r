# Export notes

The original ChatGPT Sites project remains represented in the Library as the active **Rivani Art** Site projection (project `appgprj_6a973ffc5c6881918338e07cc85ed9a7`, source version 2). The Sites projection exposes the rendered site content and project metadata but does not expose its internal generated source bundle through Library export.

For portability, this package reconstructs the site as ordinary HTML, CSS and JavaScript using the preserved 21-work storefront content and the Rivani artwork/interior assets that were recoverable from the Library. It is self-contained apart from the optional Google Fonts import; it falls back to local system fonts if offline.

No private credentials, API keys or account data are included.
